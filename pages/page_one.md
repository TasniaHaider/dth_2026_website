# The Advantages of Open-Source Software
![Advantages of open-source software](./assets/images/open_source_advantages_illustration.png)

Open-source software makes its source code available to the public. People can study, change and share it under its licence. It can give users more control and reduce costs.

## Accessibility

Students can use many open-source programmes without expensive licence fees. For example, LibreOffice provides tools for writing documents, making presentations and using spreadsheets. It offers an alternative to paid office software.

## Transparency and Flexibility

Because the source code is available, developers and other users can examine it and identify possible problems. Users with the necessary skills can also adapt the software or add features to meet their needs.

## Collaboration

Open-source projects often rely on communities that report errors, share knowledge and contribute improvements. This can help a programme develop and allow others to continue it if the original developers stop supporting it.

## Open-Source Software in Education

Open-source software is also useful in education and research. It gives students access to digital tools without requiring expensive subscriptions. Programmes such as LibreOffice and Firefox support everyday academic activities, from writing assignments to searching for information. Students can also learn more about technology by exploring how these programmes work. This makes open-source software valuable not only as a practical resource but also as a learning opportunity.
