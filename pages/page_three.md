# Voyant Tools for English Studies
![Voyant Tools digital text analysis illustration](./assets/images/voyant_tools_illustration.png)

Voyant Tools is a free, open-source platform for reading and analysing digital texts. It was developed by digital humanities scholars Stéfan Sinclair and Geoffrey Rockwell. As an English Studies student, I could upload *Jane Eyre* and use Trends to see how often a word such as "fire" appears throughout the novel. Cirrus displays frequent words in a word cloud. They do not replace close reading, but help identify patterns.

## The Five Evaluation Criteria

- **Licence:** The software uses the GPL-3.0 licence, which allows users to use, study, modify and share the code under its conditions. The README states that the web content uses a Creative Commons Attribution licence.
- **Latest commit:** The latest commit was recorded on 20 October 2026. The repository has around 2,500 commits.
- **Contributors:** GitHub lists ten contributors.
- **Issue responses:** The repository has 24 open issues. Some receive responses, while others remain unresolved. Users can report problems, but may not receive quick help.
- **Funding:** I could not find clear information about funding in the repository, so its long-term financial support is difficult to assess.

## My Evaluation

I would use Voyant as a supporting tool for thesis research, alongside close reading, and keep my own copies of texts and notes. The README explains that Stéfan Sinclair, one of the original developers, died in August 2020. Together with unclear funding, this raises questions about maintenance. However, a standalone version can be downloaded and run independently, and the GPL licence allows others to continue developing the code.
